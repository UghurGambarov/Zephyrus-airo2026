# Pitch Deck — Slayd Strukturu (8–12 slayd)

> Bu, slaydların məzmun planıdır. Slaydları ayrıca hazırlayıb
> `presentation/pitch-deck.pdf` kimi yerləşdiririk.

1. **Başlıq** — Zephyrus · City Trap · "Ağıllı şəhər üçün Sİ əsaslı aldatma şəbəkəsi".
2. **Problem** — köhnə qurğular, default parollar, analitik minlərlə logu oxuya bilmir.
3. **İdeya** — real qurğuların yanında tələlər (decoy) + Sİ aşkarlama mühərriki.
4. **Niyə tələlər güclüdür** — qanuni istifadəçi tələyə toxunmur → sıfır yanlış-pozitiv.
5. **Sİ — 3 qat** — (1) IsolationForest ML, (2) hibrid təsnifat/risk, (3) opsional LLM hesabat.
6. **Demo** — "Hücumu Başlat" → canlı siqnallar → risk + MITRE → hesabat.
7. **Kibertəhlükəsizlik dəyəri** — erkən aşkarlama, MITRE ATT&CK xəritələmə, sıfır yanlış-pozitiv.
8. **Miqyaslana bilmə** — sinif əsaslı şablonlar, mərkəzi konsol + yüngül edge, çox-saytlılıq.
9. **İnnovasiya** — aldatma + Sİ birgə; Azərbaycanda lokal olaraq yenidir.
10. **Etika və hüquq** — müdafiə, lokal mühit, saxta data, insan-dövrədə.
11. **Gələcək** — real agent inteqrasiyası, daha çox tələ şablonu, push bildirişlər.
12. **Yekun / Çağırış** — "Sİ hazırlayır, insan təsdiqləyir."
